# Reservas de salas del Centro Horizonte

El Centro Horizonte es un centro de formación ficticio que ofrece un sistema de reservas de salas para sus estudiantes, docentes y personal administrativo.

El centro cuenta con tres salas: la Sala Pequeña, con capacidad para 6 personas; la Sala Mediana, con capacidad para 12 personas; y el Auditorio, con capacidad para 40 personas.

Hay tres roles de usuario: estudiante, docente y administrador. Cada rol tiene permisos y límites distintos, que se describen en los documentos de roles y de cuotas.

El sistema permite crear, modificar y cancelar reservas, hacer check-in al llegar a la sala y consultar la disponibilidad de cada sala.

El sistema no gestiona pagos ni facturación. El uso de las salas es gratuito para todos los roles.
